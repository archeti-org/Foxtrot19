=================================
Purchase Product Attachments Link
=================================

This module creates a zip file with all the attachments related to
the products of a Purchase Order and creates a link to download this file.

* this link will be available for a certain number of days, if not regenerated before.
* the number of days is determined by the system parameter *purchase_product_attachments_link.url_days*.
